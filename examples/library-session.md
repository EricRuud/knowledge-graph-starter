# Fictional library session

Date: 2026-01-12. Owner: Demo Librarian. Attendee: Demo Coordinator.

This session was invented for this starter; it describes no real organization.

Demo Librarian replaces the old 7-day loan period with a 14-day loan period.
The imaginary shelf holds 40 items. The librarian undertakes a plan to send
reminders 2 days before the due date, pending capture review. The librarian
explicitly states that defining the due date enables the reminder schedule.

Demo Coordinator challenges the reminder interval pending evidence, asks
whether to add a return slot, and suggests exploring seed lending without
committing to it.
